# Pacman
The OG Game we all know!

## Description
The Pacman game is made using Java!! This is my first game developed using Java. The pacman will go all around the maze to collect the food which gets more score,
and the ghosts will be moving around randomly. The Pacman will have 3 lives after that the game ends!

## Getting started
### Dependencies 
- Java Development kit (JDR) 21 or later
- JRE to run the game.
### Installing
- Open the Releases section
- Download Pacman.jar
- Make sure java 21 or later is installed on your computer
### Executing Program
- Open the terminal in folder having Pacman.jar and run 'java -jar Pacman.jar'
- Alternatively , double click Pacman.jar if your system is configured to open Java applications.


## Limits of projects
- The Ghosts don't follow any proper logic to catch the Pacman
- There is no Fruits or Special ghost appearance
- There is no proper restart button but the game can be restarted by pressing any key!
